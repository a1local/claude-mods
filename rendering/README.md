# Rendering mods

For long video, animation and 3D renders, so you can see how far along they are and when they'll finish without opening a terminal.

| Mod | What it does | Install |
| --- | --- | --- |
| [render-progress](render-progress/) | A progress bar above the prompt for every render on the computer, with a notification when one finishes, fails or stalls. Works with Remotion, Remotion Lambda and any command that can report frames, such as a Blender queue. | `/plugin install render-progress --marketplace a1local/claude-mods` |
