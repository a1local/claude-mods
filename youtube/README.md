# YouTube mods

For channels that publish on a schedule and are working towards the YouTube Partner Program.

| Mod | What it does | Install |
| --- | --- | --- |
| [publish-schedule](publish-schedule/) | A pane of today's and tomorrow's uploads with what's due, overdue or done, and a reminder above the prompt within the hour. Open it with `/publishing`. | `/plugin install publish-schedule --marketplace a1local/claude-mods` |
| [channel-stats](channel-stats/) | Subscribers and views in the status line against the 1,000-subscriber bar, and a daily change table with `/channel-stats`. Needs a free YouTube Data API key. | `/plugin install channel-stats --marketplace a1local/claude-mods` |
